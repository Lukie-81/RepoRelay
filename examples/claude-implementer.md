# Claude implementer example

In a separate local Claude Code session:

1. Read `.ai-handoff/NEXT_TASK.md` and the repository's applicable instructions.
2. Confirm the requested scope before editing anything.
3. Implement only that scope using the local Claude workflow and run relevant
   verification commands.
4. Write implementation details and evidence to `.ai-handoff/RESULT.md`.
5. Update `.ai-handoff/STATE.json` after the result is complete.

RepoRelay does not require or bundle the Claude Agent SDK. Claude is an
independent implementer, not an MCP capability exposed by RepoRelay.
